## 🧭 작업 개요

이번 작업은 단순히 디자인을 수정하는 것을 넘어, **전역 헤더의 인터랙션 시스템을 재설계**하는 데 집중했습니다. 특히 데스크탑과 모바일의 UI 패턴을 분리하고, 레이어 구조를 정돈하여 애니메이션 잔상과 접근성 문제를 근본적으로 해결했습니다.

---

## ✅ 주요 작업 내역

### 🧱 전역 헤더 구조 개선
* **레이어 역할 분리:** `Header`, `Flyout Panel`, `Curtain`, `Page Content`의 위계 명확화
* **상태 관리:** Hover 중심에서 **Click & Keyboard 기반**의 명확한 상태 관리로 전환
* **시각적 정돈:** 프로젝트 톤에 맞춘 배경색(Background Tone) 및 Surface 구조 개선

### 🖥️ 데스크탑 vs 📱 모바일 동작 분리
| 구분 | 데스크탑 (Desktop) | 모바일 (Mobile) |
| :--- | :--- | :--- |
| **패턴** | **Flyout / Popover** | **Fixed Fullscreen Panel** |
| **구조** | 헤더 하단에서 자연스럽게 확장 | 화면 전체를 점유하는 모달 내비게이션 |
| **특징** | 기존 Apple 스타일 흐름 유지 | 독립된 Search / Basket / Menu 흐름 |

### 🎞️ 애니메이션 및 인터랙션 디테일
* **Stagger Animation:** 패널 내부 콘텐츠가 위에서 아래로 순차 등장하는 시차 효과 적용
* **전환 시퀀스 최적화:**
    * **Open:** `Background` → `Panel` → `Inner Content`
    * **Close:** `Inner Content` → `Panel` → `Background`
* **일관성 확보:** 메인 메뉴 외에 검색 및 장바구니 패널에도 동일한 애니메이션 시스템 확장

### ♿ 접근성(A11y) 및 모바일 최적화
* **Focus 제어:** 패널 오픈 시 `Focus Trap` 구현 및 닫기 후 트리거 버튼으로 `Focus Return`
* **스크롤 잠금:** 모바일 패널 활성화 시 `Body Scroll Lock` 적용 (배경 간섭 차단)
* **iOS 대응:** 검색 Input 폰트 크기를 **16px 이상**으로 유지하여 자동 확대 방지
* **Reduced Motion:** 환경 설정에 따른 불필요한 트랜지션 제거 대응

## 🧨 핵심 해결 과제 (Troubleshooting)

### 1. 레이어 잔상 및 층 분리 현상
> 패널 전환 시 이전 레이어의 흔적이 남는 문제는 단순 수치 조정이 아닌 **구조적 역할 분리**로 해결했습니다. 레이어별 우선순위를 재설정하고 상태 제거 타이밍을 애니메이션 종료 시점에 맞췄습니다.

### 2. 모바일 Curtain(배경) 역할 재판단
> 배경 레이어를 움직임의 주체가 아닌 **안정적인 Surface**로 보았습니다. 배경은 고정된 채로 패널과 내부 콘텐츠만 움직이게 하여 모바일에서의 화면 덜컹거림을 방지했습니다.

## 💡 인사이트 및 회고

* **구조가 우선:** 애니메이션 문제는 대부분 레이어 구조와 상태 관리 타이밍의 문제입니다.
* **패턴의 분리:** 데스크탑과 모바일은 서로 다른 UI 패턴으로 관리할 때 인터랙션이 가장 안정적입니다.
* **디테일의 힘:** 16px 폰트 유지나 Stagger 효과 같은 작은 차이가 전체 UX의 완성도를 결정합니다.
