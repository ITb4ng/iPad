> **작업 브랜치:** `feat/portfolio-polish`

## 작업 개요

이번 작업은 기존 `iPad 11` 프로젝트를 단순 UI 클론 결과물로 두지 않고,  
포트폴리오용 리뉴얼 프로젝트로 다시 설명할 수 있도록 구조와 문서를 정리하는 데 초점을 맞췄다.

특히 이 날 작업에서는 아래 두 가지를 중심으로 진행했다.

- 링크와 버튼 역할을 기준으로 마크업 정책 정리
- 제품 내비게이션과 404, 내부 이동 흐름의 맥락 보정

## 인사이트 및 회고

- 포트폴리오형 리뉴얼은 화면을 더 화려하게 만드는 것보다, 왜 이런 구조와 인터랙션을 선택했는지 설명 가능하게 만드는 일이 중요했다.
- 마크업 역할 정리는 HTML 태그 수준의 치환 작업이 아니라, 사용자 흐름과 정보 구조를 다시 분류하는 작업에 가까웠다.
- 404와 내부 이동 같은 주변 흐름도 프로젝트 완성도를 판단하는 중요한 기준이라는 점을 다시 확인했다.
